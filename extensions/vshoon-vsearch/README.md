# VSearch

IntelliJ IDEA의 **Find in Path** 를 VS Code에서 쓰기 위한 개인용 확장입니다.
`Shift` 두 번으로 모달을 띄우고, 상단에 검색 결과 파일 목록, 하단에 **편집·저장 가능한 미리보기**가
있는 한 화면 검색/치환 패널을 제공합니다. VShoon 에 내장되어 있습니다.

---

## 1. 사용법

### 여는 방법
| 방법 | 설명 |
| --- | --- |
| **`Shift` 두 번** | 검색 창 열기 (에디터에서 선택한 텍스트가 있으면 검색어로 자동 입력) |
| `Ctrl+Shift+Alt+R` | 바꾸기 입력칸까지 열어서 시작 |
| 탐색기에서 폴더 우클릭 → `VSearch: 이 폴더에서 검색` | 그 폴더로 범위를 지정해 열기 |
| `Ctrl+Shift+P` → `VSearch` | 명령 팔레트로 열기 |

> **`Shift` 두 번이 동작하지 않으면** — VS Code는 1.54부터 `shift shift` 같은 더블 modifier 키를 지원하지만,
> 확장이 기본 제공하는 경로가 막혀 있을 수 있습니다. 그럴 때는 `Ctrl+Shift+P` → `기본 설정: 바로 가기 키 열기(JSON)`
> 에서 아래를 추가하세요. (단축키 GUI 편집기로는 같은 키를 두 번 입력할 수 없어 JSON을 직접 써야 합니다)
> ```json
> { "key": "shift shift", "command": "vsearch.open" }
> ```

### 표시 형태 — 모달

전체 검색 패널은 워크벤치 **모달**로 열립니다. IntelliJ 의 Find in Path 처럼 편집기 위에 가운데
정렬된 오버레이로 떠서, 편집기 그룹이나 탭을 차지하지 않습니다.

- UI는 모달을 **꽉 채웁니다.** 결과 목록 높이는 모달 높이에 맞춰 자동으로 늘어나고,
  가운데 분할선을 드래그하면 그 이후로는 지정한 높이를 유지합니다.
- `Esc` 로 닫습니다. (검색 중이면 먼저 검색을 중지합니다) 모달 밖을 클릭해도 닫힙니다.
- **결과를 더블클릭(또는 `Enter`)하면 그 파일은 편집기에서 열립니다.** 모달을 닫으면 보입니다.
- 이미 검색 패널이 열려 있으면 새로 만들지 않고 그 패널을 앞으로 가져옵니다.
- 모달은 VShoon 이 제공하는 표시 방식입니다. 일반 VS Code 에서 이 확장을 쓰면 같은 호출이
  평범한 편집기 탭으로 열립니다. `workbench.editor.useModal` 을 `off` 로 두어도 같습니다.

### 화면 구성
```
┌──────────────────────────────────────────────────────────┐
│ 🔍▾ 검색어              ✕ ⇄ │ Cc W .* │ *.ts, *.java ▾  │
│ ⇄   바꿀 내용              [바꾸기] [모두 바꾸기]          │ ← ⇄ 켰을 때만
├──────────────────────────────────────────────────────────┤
│ 📁  [경로.................] […] ☑하위 포함                │
│     └ 📁 켰을 때만 나타남                                  │
├──────────────────────────────────────────────────────────┤
│ #!/usr/bin/env sh                       docker-compose  1│ ← 결과 (평면 목록)
│ # Copyright 2015 the original authors.  gradlew         4│
├───────────────── 드래그로 크기 조절 ──────────────────────┤
│ 파일경로                                            🔍     │
│ ┌ 🔍▾ 찾기        Cc W .* ┐  3 / 12  ↑ ↓            ✕     │ ← Ctrl+F
│ 미리보기 (직접 수정 후 Ctrl+S 저장 가능)                    │
├──────────────────────────────────────────────────────────┤
│ 16개 파일에서 97건 (0.32초)          [에디터에서 열기]     │ ← 상태 바
└──────────────────────────────────────────────────────────┘
```

결과는 IntelliJ처럼 **파일 그룹 없는 평면 목록**입니다. 한 줄이 일치 한 건이고,
왼쪽에 해당 줄 내용(일치 부분 강조), 오른쪽 끝에 파일명과 줄 번호가 붙습니다.

검색어를 입력하면 **입력하는 중에 자동으로** 검색됩니다(0.3초 지연). 별도 검색 버튼은 없습니다.

창을 열 때는 항상 **빈 상태로 시작**합니다. 지난번 검색어나 옵션은 남지 않고, 최근 기록만 보관됩니다.

### 검색 조건
- `Cc` 대소문자 구분 · `W` 단어 단위 · `.*` 정규식 · `⇄` 바꾸기 행 열기 · `✕` 검색어 지우기
- **범위**: 기본은 프로젝트 전체입니다. 두 번째 줄 왼쪽의 `📁` 버튼을 켜면 그 오른쪽에 경로 입력과
  `…`(폴더 선택), `하위 포함` 이 나타나 그 디렉터리만 검색합니다. (`Alt+D`)
  - 경로가 비어 있을 때 `📁` 를 켜면 폴더 선택 창이 바로 뜹니다.
  - `하위 포함` 을 끄면 그 폴더의 **직속 파일만** 검색합니다.
- **다중 선택**: `Ctrl+클릭` 으로 하나씩 더하고, `Shift+클릭` 으로 범위를 잡습니다.
  여러 개를 고른 뒤 하단 `에디터에서 열기` 를 누르면 선택한 파일이 모두 열립니다(같은 파일은 한 번만).
- **최근 기록**: 검색어(`🔍▾`) · 바꿀 내용(`⇄▾`) · 파일 마스크(`▾`) · 파일 내 찾기(`🔍▾`) 네 곳 모두
  드롭다운으로 최근 값을 고를 수 있습니다. 각각 최대 15개이며, 입력을 마치거나 `Enter` 를 누른 값이 쌓입니다.
  목록에서 항목에 마우스를 올리면 오른쪽에 `✕` 가 나타나 그 기록만 지울 수 있습니다.
- **파일 마스크** (검색란 오른쪽 끝 입력칸): `*.ts, *.java` 처럼 쉼표로 여러 개

### 단축키 (패널 안에서)
| 키 | 동작 |
| --- | --- |
| `Enter` (검색어칸) | 지연 없이 즉시 검색 |
| `↑` `↓` `PageUp` `PageDown` `Home` `End` | 결과 이동 |
| `Ctrl+클릭` / `Shift+클릭` / `Shift+방향키` / `Ctrl+A` | 결과 **다중 선택** |
| `Enter` (결과 목록) / 더블클릭 | **메인 창**의 편집기에서 열기 (여러 개 선택 시 전부) |
| `F3` / `Shift+F3` | 미리보기에서 다음/이전 일치로 이동 |
| `Ctrl+F` (미리보기 안) | VS Code 와 같은 **찾기 위젯** 열기 |
| `Ctrl+S` | 미리보기 편집 내용 저장 (별도 저장 버튼은 없습니다) |
| `Ctrl+Enter` | 현재 위치를 편집기에서 열기 |
| `Esc` | 검색 중이면 중지, 아니면 검색 창 닫기 |
| `Alt+C` / `Alt+W` / `Alt+E` | 대소문자 / 단어 단위 / 정규식 토글 |
| `Alt+R` / `Alt+D` | 바꾸기 행 / 디렉터리 범위 토글 |

### 미리보기 — VS Code 편집기(Monaco)

미리보기에는 VS Code 가 실제로 쓰는 **Monaco 에디터**가 들어갑니다. 그래서 편집기와 똑같이 동작합니다.

- **문법 강조**, 괄호 매칭, 자동 들여쓰기, 코드 접기 (미니맵은 좁은 창에서 방해되어 꺼 뒀습니다)
- **`Ctrl+F` 는 VS Code 와 똑같은 찾기 위젯** 입니다 (미리보기 헤더의 돋보기 버튼으로도 열립니다)
- 검색어와 일치하는 곳은 노란 배경으로 표시됩니다. 일치 항목 사이 이동은 `Ctrl+F` 찾기 위젯을 쓰세요
- `Ctrl+S` 로 저장합니다. 수정 중이면 파일 경로 옆에 `●` 가 붙습니다
- 테마는 VS Code 를 따라갑니다(라이트/다크/고대비). 테마를 바꾸면 즉시 반영됩니다
- 다른 파일을 봤다가 돌아와도 **편집하던 내용이 남습니다**

### 바꾸기
1. 검색어 오른쪽의 `⇄` 버튼(또는 `Alt+R`)을 누르면 **바꾸기 행이 나타납니다** → 바꿀 내용 입력
2. `바꾸기` = 결과 목록에서 **선택한 한 건만**, `모두 바꾸기` = **현재 검색 조건의 전체**
3. `모두 바꾸기`는 확인 대화상자가 뜹니다. 실행 후 `Ctrl+Z` 로 되돌릴 수 있습니다.
4. 정규식 모드에서는 바꿀 내용에 `$1`, `$&` 같은 그룹 참조를 쓸 수 있습니다.

## 2. 설정 (`Ctrl+,` → `vsearch` 검색)

| 설정 | 기본값 | 설명 |
| --- | --- | --- |
| `vsearch.maxFileSizeKb` | 5120 | 이보다 큰 파일은 검색하지 않음 |
| `vsearch.maxFiles` | 20000 | 검색 대상 파일 수 상한 |
| `vsearch.maxResultFiles` | 3000 | 결과 파일 수 상한 |
| `vsearch.maxMatchesPerFile` | 500 | 파일당 표시할 일치 수 |
| `vsearch.excludeGlobs` | `[]` | 항상 제외할 glob 목록 |
| `vsearch.autoSearch` | `true` | 입력 중 자동 검색(0.3초 지연) |
| `vsearch.saveAfterReplace` | `true` | 바꾸기 후 자동 저장 |
| `vsearch.maxPreviewSizeKb` | 2048 | 미리보기에 로드할 최대 크기 |
